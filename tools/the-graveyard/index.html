How it works

  1. The prize is locked onchain. The Zombie is sent into the raffle contract. From then on it can only go to a winner. If the giveaway is cancelled before the draw, it goes back to the owner.
  2. One ticket per Zombie. Every Zombies On Base token held at the snapshot is one ticket.
  3. No listed wallets. When the giveaway closes, any wallet with a Zombie listed on OpenSea is excluded. The collection owner wallet is excluded too.
  4. Public snapshot. The full ticket list is published, and its Merkle root is recorded in the contract before the draw.
  5. Chainlink VRF draws. Anyone can request the draw. Chainlink VRF v2.5 returns a verifiable random number onchain.
  6. Prize delivered by the contract. The winning ticket is fixed the moment Chainlink's number arrives. Anyone can settle: the contract checks the ticket's proof against the committed list and sends the Zombie to the holder recorded in the snapshot. Nothing that happens after the snapshot can change the winner.

1 · Start a giveaway

2 · Commit the snapshot

After it closes, the snapshot is published on this site and loads here automatically. Committing is blocked unless the published file is live and matches exactly.

Cancel

Only possible before a draw is requested. Returns the prize to your wallet.
